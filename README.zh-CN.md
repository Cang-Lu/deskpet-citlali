# 茜特菈莉 · 桌面宠物

[English](README.md) · **简体中文**

一个**独立运行**的桌面宠物，支持 Windows / macOS / Linux。它不运行在 DeepSeek Harness、Codex 或任何 agent 宿主里——它就是一个应用。

- 主角是《原神》的**茜特菈莉**，使用社区精灵图素材（见[素材与许可](#素材与许可)）。
- 通过 **DeepSeek API** 对话，回复以气泡形式显示在她头顶。
- 一套**状态机**驱动动画与粒子特效：待机、思考、说话、开心、失落、打瞌睡、走动、看书……
- 她有自己的**脾气**：先找地方定居，换几个姿势，溜达到新位置，路上还会自言自语。
- **鼠标靠近**她会坐起来看着你，用的是图集里那 16 个视线方向。

---

## 快速开始

需要 **Node.js 20 或更高版本**（开发时用的是 Node 24）。

```bash
npm install
npm start
```

首次运行她会打个招呼，并提示你还没有配置 API Key。**右键桌宠**（或右键托盘图标）→ **设置…**，把 Key 填进去即可。

### 直接下载 Windows 可执行文件

到 [Releases](../../releases) 页面下载，**不需要装 Node.js**：

| 文件 | 说明 |
| --- | --- |
| `Citlali-Setup-x.y.z.exe` | 安装版。可以选安装目录，会创建开始菜单和桌面快捷方式。 |
| `Citlali-Portable-x.y.z.exe` | 免安装单文件版。双击就能跑。 |

两个都是自包含的，约 90MB（这是 Electron 的底噪，不是应用本身的体积）。

> 构建产物**没有代码签名**，所以 Windows SmartScreen 首次运行会拦截。选「更多信息」→「仍要运行」，或者自己从源码构建。

### 自己构建 exe

```bash
npm install
npm run dist            # 安装版 + 免安装版，输出到 dist/
npm run dist:installer  # 只做安装版
npm run dist:portable   # 只做免安装版
npm run dist:dir        # 只出解包目录；最快，不用下载 NSIS
```

打包配置里有三处是刻意的：

- **关掉了 `npmRebuild`。** 这个项目没有任何原生依赖，重建步骤只会要求一套它根本不需要的工具链。
- **渲染层走 `fs` 读取，而不是 `net.fetch`。** 打包进 `app.asar` 后只有 Electron 的 `fs` 认识 asar 路径；把 `file:` URL 交给文件加载器会 404，结果是图集加载失败、窗口一片空白。
- **`build/icon.png` 是生成的**，不是手绘的：`npm run slice` 会从精灵图裁出 256×256，交给 electron-builder 转成 `.ico`。

### 如果 `npm install` 在 Electron 的 postinstall 步骤失败

个别受限环境（沙箱、某些企业安全策略）不允许安装脚本派生子进程。绕过办法是自己下载 Electron 二进制：

```bash
npm install --ignore-scripts
node tools/install-electron.mjs          # 打印出 ZIP= 和 DEST= 两行
# 然后解压 ZIP 到 DEST，并把 "electron.exe" 写进 node_modules/electron/path.txt
```

### 获取 DeepSeek API Key

到 <https://platform.deepseek.com> 注册并创建 Key（形如 `sk-…`），填进设置。点「测试连接」可以立即验证。

Key 通过 Electron 的 `safeStorage` 用系统密钥库（Windows 上是 DPAPI）**加密后**保存，并且**永远不会传给渲染进程**——设置界面只显示「已保存」，不回显明文。

> 填完记得点输入框右边的**「保存」**（按回车、或点「完成」也会保存）。保存后提示会变成「已保存，并使用系统密钥库加密存储」。

### 用的什么模型

默认 **`deepseek-chat`**（DeepSeek V3 非思考模式），接口 `https://api.deepseek.com`。模型名和接口地址都可以改，兼容任何 OpenAI 协议的服务。

## 工作模式：让她认真回答

默认状态下她把回复压在 **1~3 句、60 字以内**。这是人设里的硬约束——适合桌宠，但你真要问点正事时就不够用。

打开**工作模式**后：

- **解除长度限制**，允许长篇、Markdown（标题/列表/表格）和完整可运行的代码块
- **准确性优先于可爱**：不确定会直说，信息不足会先问，不编造 API 和参数
- 复杂问题先给结论或可执行步骤，再补解释
- 角色语气保留，但口癖收敛成偶尔一句，不影响信息密度
- **闲聊时依然是原来的语气**——主动搭话和打招呼不会突然变成说明书

| | 闲聊模式 | 工作模式 |
| --- | --- | --- |
| 温度 | 1.15 | 0.6 |
| 回复上限 | 700 tokens | 2400 tokens |
| 气泡高度 | 172px | 320px（窗口自动变高） |

**三种切换方式：**

- 在对话里输入 **`/work`** 进入、**`/pet`** 退出（也认 `/工作`、`/闲聊`）。这两种命令**本地处理，不消耗请求**。
- 托盘 / 右键菜单 → **工作模式**
- 设置 → 模型 → 工作模式

输入框提示文字和气泡边框会跟着变，不会搞不清当前在哪个模式。

## 怎么玩

| 操作 | 效果 |
| --- | --- |
| 左键单击她 | 打开输入框（`Enter` 发送，`Esc` 收起） |
| 按住拖动 | 把她搬到屏幕任意位置，位置会被记住 |
| **`Ctrl` + 滚轮** | **就地放大 / 缩小她** |
| 右键她 / 右键托盘图标 | 菜单：大小、显示隐藏、设置、置顶、穿透、开机自启、自主行为、查询余额、退出 |
| `Ctrl+Enter` | 在任意时刻唤出输入框（窗口有焦点时） |
| 把鼠标移近她 | 她放下小说坐起来看你；离开约 300px 就回去看书 |

气泡里的文字可以选中复制。**每句话都会自动隐藏**，不会一直挡着屏幕——短句 5 秒。想再看一眼，点她一下就会把最后一句调回来。对话记忆保存在本地，托盘菜单和设置页都能清空。

### 长回答会被保护

| 场景 | 行为 |
| --- | --- |
| 回答停留多久 | 随内容变长：7 秒起，每字 +90ms，最长 60 秒 |
| 你还没读完 | 她**原地不动、不吭声**，直到气泡收起（最长 25 秒） |
| 她的自言自语 | 回答在屏幕上时**直接跳过**，绝不会盖掉你正在看的内容 |
| 回答被关掉了 | 点她一下就能**原样调回来**；回答和闲聊分开保存，闲聊顶不掉回答 |
| 想看更早的 | 托盘 / 右键菜单 → **对话记录…** |

原来的问题是三个缺陷叠在一起：气泡一律 5 秒隐藏、自言自语复用了同一个气泡（还顺手覆盖了唯一的一份存档）、行为引擎完全不知道有人在看东西。

## 调整大小与画质

### 大小：无级可调

- **`Ctrl` + 滚轮**：鼠标放在她身上滚，每次 16px。
- **设置 → 外观与窗口 → 大小**：96–900px 滑块，1px 一档。
- **托盘 / 右键菜单 → 大小**：小/中/大/很大，以及 ±8px / ±32px 微调。

改完立即生效，没有被吸附到固定档位。

### 渲染方式

| 模式 | 行为 | 什么时候用 |
| --- | --- | --- |
| **超采样自适应**（默认） | 按整数倍把这一帧超采样到离屏缓冲，再缩放到你要的尺寸 | 默认就用它。任意尺寸都清晰 |
| **硬边像素** | 不做任何平滑，直接最近邻放大 | 想要那种锯齿分明的复古像素感 |

为什么默认模式能做到"任意尺寸都清晰"：先把精灵在离屏画布上按**整数倍**栅格化（这一步是最近邻，所以保持锐利），再把这块缓冲缩放到目标尺寸。目标是整数倍时最后一步就是 1:1 搬运，**像素级精确**；不是整数倍时是**降采样**而不是拉伸，所以边缘平滑而不是长满锯齿。缓冲按「帧 + 倍率」缓存，每帧只多一次 `drawImage`。

### 去边缘灰边

源美术在被抠出 alpha 之前是垫在深色背景上的，所以抗锯齿边缘像素的 RGB 是暗的。在**浅色桌面**上叠加时，这些像素会合成出一圈脏灰的描边——看起来就像角色整体发虚。

「去除边缘灰边」默认开启：启动时扫描图集，把非全不透明像素的 RGB 替换成邻近实体像素的颜色，**alpha 完全不动**。实测整张 1536×2288 图集重绘约 13 万个边缘像素，耗时约 130ms，只在启动时做一次。

想对比效果可以关掉它，用 `npm run slice` 生成 `.qa/fringe-proof.png`（原始）和 `.qa/fringe-after.png`（处理后）——都是白/黑/洋红/深色四种底色上的同一块角色，灰边在白底上最明显。

### 关于状态色调

情绪色调（开心偏暖、难过偏冷、恼火偏红……）**默认关闭**，可以在设置里打开。

默认关闭是有依据的：她的坐垫是一大片接近纯白的平面，即使很低的不透明度，颜色偏移在这片平色上也肉眼可见，看起来是**角色被重新上色**而不是"被光照着"。情绪由粒子特效承担（星光、雨滴、怒气、飘 `z`、思考光点），它们完全不碰她的配色。

打开时它会被**裁剪在角色轮廓内**（绘制时用 `source-atop` 只作用在她身上），不会溢出到周围——不透明度再低也不会出现背景灰雾。

> 从旧版本升级上来？旧版把这个开关默认设成开，并且已经把你当时的配置存进了文件。现在的版本会在启动时自动迁移把它关掉。

## 账户余额

接的是 DeepSeek 官方的 [`GET /user/balance`](https://api-docs.deepseek.com/api/get-user-balance/) 接口。

- **按需查询**：托盘 / 右键菜单 →「查询余额」，或设置页的按钮。菜单里也会显示上次查到的余额。
- **定时查询**：设置页里开关，间隔可调（默认 30 分钟）。启动后约 6 秒会查一次。
- **余额不足提醒**：低于你设的阈值（默认 ¥5）时，她会弹一个**置顶不易消失**的气泡提醒你去充值，托盘菜单也会标注「偏低，建议充值」。同一个金额 12 小时内只提醒一次。

赠金和充值余额在接口返回时会一并显示。提醒用的是**本地台词**——余额都快没了还花 token 去生成提示语，那就本末倒置了。

`is_available: false`（余额不足以调用 API）会单独标出来。

## 状态与动画对照

精灵图共 11 行：第 0–8 行是标准动作，第 9–10 行是 16 个视线方向。

| 状态 | 精灵行 | 触发时机 | 特效 |
| --- | --- | --- | --- |
| 趴着看书 | 0 | 定居姿势之一（权重最高） | — |
| 趴着发呆 | 7 | 定居姿势之一 | — |
| 趴着放空 | 0（更慢） | 定居姿势之一 | — |
| 坐着歇着 | 5 | 定居姿势之一 | — |
| 坐着张望 | 8 | 定居姿势之一，**最多 7 秒** | — |
| 坐着打瞌睡 | 6 | 定居姿势之一，**最多 5 秒** | 飘 `z` |
| 睡着 | 0（最慢） | 超过设定时长无人互动 | 飘 `z` |
| 走动 | 1 / 2 | 换 2–4 个姿势之后 | — |
| 思考 | 7 | 消息已发出，等模型回复 | 冰蓝光晕 |
| 开心 / 兴奋 | 4 | 模型返回 `happy` / `excited` | 金色星光 |
| 打招呼 / 害羞 | 3 | 启动问候、点击她 | 星光 / 粉色 |
| 失落 / 恼火 | 5 | 出错、`sad` / `angry` | 雨滴 / 怒气 |
| 视线跟随 | 9 / 10 | 鼠标靠近时 | — |

**剪辑名是按画面内容起的，不是按行名**——图集的行名有误导性，详见 [docs/DEVELOPMENT-NOTES.md](docs/DEVELOPMENT-NOTES.md)。完整动画总览见 [`docs/animations.png`](docs/animations.png)。

### 她闲着的时候会做什么

行为模型很简单，和真实桌宠的观感一致：

> **在某个地方定居 → 随机切换几个姿势 → 慢慢走到新地方 → 继续定居**

**定居阶段**会从下面这些姿势里随机挑，同一个姿势不会连着出现两次：

| 姿势 | 精灵行 | 停留 |
| --- | --- | --- |
| 趴着看书 | 0 趴着看书 | 12–26 秒 |
| 趴着发呆 | 7 趴着看书（另一套动画） | 8–18 秒 |
| 趴着放空 | 0（更慢） | 7–16 秒 |
| 坐起来歇着 | 5 坐着低头 | 5–9 秒 |
| 坐着左右张望 | 8 坐着摇头 | 4–7 秒 |
| 坐着打瞌睡 | 6 坐着点头 | 3–5 秒 |

趴着和坐着大约是 **53% / 47%** 的配比，所以她会反复换姿势，而不是一直趴着。

**走动是独立的一段**，不是随机姿势之一：因为这张图集的走路美术**本身就是"坐着摇摆"**，站着不动播它看起来就是在原地走。每换 **2–4 个姿势**她就起身走一段（130–260px，约 **2.2–4.5 秒**，58px/s，动画 8fps），到了之后重新开始定居。

> 之前这里是 130px/s + 12fps（"看着非常着急"就是这个）；再之前我用第 1 行当坐姿，于是"像走路但没走路"——那行是走路的美术。

另外还有：

- **12 分钟没人理 → 打瞌睡**（`z` 粒子飘出来），你回来时她会惊讶一下
- **鼠标靠近 → 坐起来看你**，视线跟着鼠标转，离开约 300px 就回去
- **每 25 分钟**（可设）调用一次 DeepSeek 主动找你搭话

### 她说的话永远和当前动作匹配

**每一句台词都挂在姿势上**，不是共用一个池子——所以"明明醒着却说好困"这类错位在结构上就不可能发生：

| 姿势 | 台词池 |
| --- | --- |
| 趴着看书 | 看书相关：「别吵，正到精彩的地方。」 |
| 趴着发呆 | 闲聊：「你桌上那杯水，凉了吧。」 |
| 坐着张望 | 「……嗯？」「好像有动静。」 |
| 坐着打瞌睡 | **只有这个姿势**会说困话：「再看一页就睡……就一页。」 |
| 坐着低头 | 「……在想事情。」「让我静静。」 |
| 走路途中 | 「……腿都坐麻了。」 |
| 走到目的地 | 「就这儿吧。」 |
| 刚睡醒 | 「……唔，我睡着了？」 |

自检里有断言检查这张对应关系，并禁止把视线跟随的那两行用作随机姿势。

这些是**本地台词库**（9 组 41 句），不调用模型——它们是高频的环境音，为一句"……困了"花 token 不划算。「主动找你说话」是另一回事，那个会真的调用 DeepSeek，间隔也长得多（默认 25 分钟）。

情绪的驱动方式：系统提示词要求模型在回复**开头**输出一个 `[[mood:xxx]]` 标记，主进程边流式接收边把标记剥掉（所以气泡里永远不会看到它），再映射成上面的状态。

想调整活跃度，改 `src/renderer/behavior.js` 顶部的 `POSES` 表（概率、时长）和 `WALK_SPEED` 即可。

## 开发

```bash
npm start             # 正常运行
npm test              # 配置迁移单元测试（纯 Node，秒级）
npm run test:secrets  # API Key 加解密往返测试（需要 Electron）
npm run selftest      # 自检：逐状态截图 + 断言，产物在 .qa/
npm run slice         # 重新切图 / 生成托盘图标与应用图标 / 测量帧数与动作幅度
npm run fetch-assets  # 重新下载精灵图并校验 SHA-256
npm run dist          # 打包成 Windows 可执行文件（见上方「自己构建 exe」）
```

`npm run selftest` 会启动真实应用，依次切到每个状态截图到 `.qa/states/`，并断言：思考状态不会瞬间过期、视线左右映射正确、窗口可见、走动能真的移动窗口、模型错误能被干净地报出来、图集去灰边已生效、缩放是无级的（333/400/507 都精确命中）、**情绪光晕没有溢出角色轮廓**、改大小能真的改变窗口、余额接口错误被正确处理、余额不足提醒只触发一次。

加上 `DESKPET_SELFTEST_NET=1` 还会用无效 Key 真打一次 DeepSeek，验证 HTTP + SSE 链路和余额接口。

产物：`.qa/states/*.png`（逐状态截图）、`.qa/settings-window.png` 与 `-2.png`（设置页上下两部分）、`.qa/history-window.png`、`.qa/low-balance.png`、`.qa/selftest.json`（报告）。

排查界面问题时可以用 `tools/inspect-shot.js` 把任意截图裁切放大并打印像素采样：

```bash
electron tools/inspect-shot.js <图片路径> .qa/inspect
```

调试时渲染进程暴露了 `window.__deskpet`：可以 `__deskpet.setBase('sleepy')`、`__deskpet.setOverlay('happy')`、`__deskpet.setLook(4)`、`__deskpet.setSize(600)`、`__deskpet.measureBackground()`、`__deskpet.info` 等。

设置与对话记忆默认存在系统用户数据目录（可用环境变量 `DESKPET_DATA_DIR` 覆盖，方便做便携或隔离运行）。

改动任何不直观的地方之前，先读 [docs/DEVELOPMENT-NOTES.md](docs/DEVELOPMENT-NOTES.md)——里面记录了当前设计背后的实测数据和走过的弯路（哪些精灵行实际画的是什么、为什么要用主进程轮询光标、为什么状态色调默认关闭）。
